## Правила

- Рабочая ветка: `main`.
- Источник требований: `TASKS.txt`.
- Изменения поставляются тремя функциональными пакетами.
- WEB и сервер локально не запускать.
- Тестирование и production build выполняются владельцем проекта.
- После каждого пакета обновлять этот файл.
- Не считать наличие таблицы или DTO завершённой пользовательской функцией.
- `PlatformRoutes.kt` пока не разделять.
