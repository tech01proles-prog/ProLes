Последнее обновление: 2026-09-25

## Правила текущего этапа

- Рабочая ветка: `main`.
- `PlatformRoutes.kt` не разделять.
- Текущий приоритет: крупные визуальные и функциональные обновления WEB.
- SERVER менять только при необходимости для функций WEB.
- WEB-клиент самостоятельно не разворачивать и не запускать.
- Тесты, сборку и ручную проверку оставить на финальный этап.
- После каждого пакета обновлять этот файл.

- `DataRoutes.kt` очищен до минимального агрегатора.
- Добавлена валидация payroll-периодов, дат и статусов.
- Устранена вложенная транзакция при загрузке ticket-файлов.
- Добавлены ограничения и нормализация ticket-файлов.

- Добавлена компенсационная очистка ticket-файлов при сбое БД.
