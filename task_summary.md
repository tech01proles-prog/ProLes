### Проблема:
В текущей версии экрана аналитики нет возможности переключаться между месяцами. Данные показываются только за текущий месяц.

### Решение:
Добавить:
- Состояние `selectedMonth` для выбора месяца
- Выпадающий список или навигацию для выбора месяца
- Обновление всех расчётов при изменении месяца
- Принудительную подгрузку доходов при переключении месяца
